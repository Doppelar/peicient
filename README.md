# peicient — 血液がんの患者数の推計と病院

血液内科で扱うがん（多発性骨髄腫・骨髄性白血病〈AMLが中心〉・白血病・悪性リンパ腫・DLBCL・ろ胞性リンパ腫）について、全国がん登録の罹患率を市区町村の人口に当てはめた推計患者数と、厚生労働省 DPC データの病院ごとの退院件数を、地図と表で見られる静的サイトです。市区町村を選んで担当エリアの合計も出せます。

## 推計のしかた

- **年間新規患者数** ＝ Σ（市区町村の年齢5歳階級・性別ごとの人口 × 同じ年齢・性別の罹患率）
  - 罹患率は全国がん登録の都道府県別（または全国）罹患数 ÷ 人口。最新3年（2021〜2023年）の平均。85歳以上はまとめて1区分。
  - 人口は住民基本台帳の年齢階級別人口（市区町村別・日本人と外国人の合計）。
- **5年有病者数（概算）** ＝ 年間新規患者数 × Σ_{k=0..4} S5^((k+0.5)/5)
  - S5 は5年相対生存率（2018年診断、性別）。生存率が5年間で一定の割合で下がると仮定した目安です。

人口が罹患率の年より新しいため、高齢化の分だけ登録の実数より多めに出ます。

- **骨髄性白血病・DLBCL・ろ胞性リンパ腫** は都道府県別の集計がないため、白血病（C91-C95）・悪性リンパ腫の年齢別の率に、全国の詳細部位（C92・C83・C82）の割合（性別、2021〜2023年）を掛けて推計します。AML だけの集計は全国がん登録にないため、C92（CML なども含む）で示します。
- **病院** は DPC 退院患者調査（令和2・3・5年度。令和4年度は病院別の表が見つからない）の「疾患別手術別集計 MDC13」の退院件数（手術なし＋その他の手術あり）。10件未満は公表されていないため「以上」などで示します。地図の丸は所在市区町村の中心付近に置いています。

## データの更新

`public/data/*.json` は次の元データから `scripts/build-data.mjs` で作ります。

1. 国立がん研究センター がん情報サービス「[がん統計 集計表ダウンロード](https://ganjoho.jp/reg_stat/statistics/data/dl/index.html)」から
   - `pref_cancer_incidenceNCR(2016-2023).xls`（都道府県別がん罹患データ）
   - `cancer_survivalNCR(2016-2018).xlsx`（全国がん登録 5年生存率）
2. 総務省「[住民基本台帳に基づく人口、人口動態及び世帯数](https://www.soumu.go.jp/main_sosiki/jichi_gyousei/daityo/jinkou_jinkoudoutai-setaisuu.html)」から
   - 【総計】年齢階級別人口（市区町村別）の xlsx を `muni_age.xlsx` という名前で保存
3. 同じダウンロードページの `cancer_incidenceNCR(2016-2023).xls`（全国の詳細部位）
4. 厚生労働省「DPC導入の影響評価に係る調査『退院患者調査』の結果報告」から
   - 年度ごとに「疾患別手術別集計_MDC13」を `dpc_mdc13_<年度>.xlsx`、「施設概要表」を `dpc_facilities_<年度>.xlsx` という名前で保存（例：`dpc_mdc13_2023.xlsx`）。置いた年度がすべて画面で切り替えられます。告示番号は年度で変わるため、病院は「所在市区町村＋病院名」で年度をまたいで結びつけます
5. （任意）国立がん研究センター「[院内がん登録症例集計結果閲覧システム](https://jhcr-cs.ganjoho.jp/hbcrtables/)」の「集計対象施設一覧」を `hbcr_facilities.xlsx` という名前で保存（病院の「がん拠点」表示に使います）
6. （任意）同じシステムの「[部位別登録数](https://jhcr-cs.ganjoho.jp/hbcrtables/wpSiteSearch.aspx?UnitType=2)」で部位（多発性骨髄腫・白血病・悪性リンパ腫）と診断年を1年ずつ選び「▼CSV出力」したファイルを、名前を変えずに置く（`院内がん登録データ_2023-2023_多発性骨髄腫.csv` と `…（都道府県全体）.csv`）。病院ごとの新規登録数として、診断年で切り替えて表示します
7. （任意）同じ部位別登録数で内訳（性別・年齢・住所・来院経路・症例区分・発見経緯・告知）を選んで出力した CSV を、内訳の名前のフォルダ（例：`data-raw/住所/`）に名前を変えずに置く。10件以上の病院の内訳を病院の表に出し、住所の「都道府県全体」の表から都道府県をまたぐ患者の移動を矢印の地図にします。住所の病院ごとの表からは、病院ごとに他県から来た人の地図も作ります

`public/geo/japan.json`（移動の地図の都道府県の輪郭）は `node scripts/build-japan.mjs` で市区町村の地図から作ります。

これらを同じフォルダ（例：`data-raw/`、git には入れない）に置いて実行します。

```bash
npm run data -- data-raw
```

新しい年のファイルが出たら、ファイル名と `build-data.mjs` の `YEARS` を合わせて更新してください。

## 開発

```bash
npm install
npm test        # 推計の計算のテスト（vitest）
npm run dev
npm run build
```

## 出典

- 国立がん研究センターがん情報サービス「がん統計」（全国がん登録）
- 総務省「住民基本台帳に基づく人口、人口動態及び世帯数」
- 厚生労働省「DPC導入の影響評価に係る調査『退院患者調査』の結果報告」（令和5年度）
- 国立がん研究センター 院内がん登録症例集計「集計対象施設一覧」
- 地図：国土交通省 国土数値情報（行政区域）を SmartNews Media Research Institute が加工した TopoJSON（[japan-topography](https://github.com/smartnews-smri/japan-topography)）、`public/geo/`

推計値はこのサイトで計算したもので、出典元によるものではありません。
