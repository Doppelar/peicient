# peicient — がん患者数の推計（全国がん登録から）

都道府県の年齢別・性別のがん罹患率を、市区町村の人口に当てはめて、地域ごとの年間新規患者数と5年有病者数（概算）を推計する静的サイトです。市区町村を複数選んで、担当エリアなどの合計も出せます。

## 推計のしかた

- **年間新規患者数** ＝ Σ（市区町村の年齢5歳階級・性別ごとの人口 × 同じ年齢・性別の罹患率）
  - 罹患率は全国がん登録の都道府県別（または全国）罹患数 ÷ 人口。最新3年（2021〜2023年）の平均。85歳以上はまとめて1区分。
  - 人口は住民基本台帳の年齢階級別人口（市区町村別・日本人と外国人の合計）。
- **5年有病者数（概算）** ＝ 年間新規患者数 × Σ_{k=0..4} S5^((k+0.5)/5)
  - S5 は5年相対生存率（2018年診断、性別）。生存率が5年間で一定の割合で下がると仮定した目安です。

人口が罹患率の年より新しいため、高齢化の分だけ登録の実数より多めに出ます。

## データの更新

`public/data/*.json` は次の元データから `scripts/build-data.mjs` で作ります。

1. 国立がん研究センター がん情報サービス「[がん統計 集計表ダウンロード](https://ganjoho.jp/reg_stat/statistics/data/dl/index.html)」から
   - `pref_cancer_incidenceNCR(2016-2023).xls`（都道府県別がん罹患データ）
   - `cancer_survivalNCR(2016-2018).xlsx`（全国がん登録 5年生存率）
2. 総務省「[住民基本台帳に基づく人口、人口動態及び世帯数](https://www.soumu.go.jp/main_sosiki/jichi_gyousei/daityo/jinkou_jinkoudoutai-setaisuu.html)」から
   - 【総計】年齢階級別人口（市区町村別）の xlsx を `muni_age.xlsx` という名前で保存

3つを同じフォルダ（例：`data-raw/`、git には入れない）に置いて実行します。

```bash
npm run data -- data-raw
```

新しい年のファイルが出たら、ファイル名と `build-data.mjs` の `YEARS` を合わせて更新してください。

## 開発

```bash
npm install
npm test        # 推計の計算のテスト（vitest）
npm run dev
npm run build
```
